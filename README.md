🚀 PX Cloudflare 工作者面板
一个基于 Cloudflare Workers 部署的轻量级代理节点与订阅管理面板，无需自备服务器，借助 Cloudflare 全球边缘网络实现高效中继。

✨ 项目特性
💡 零成本运行：无需购买 VPS，部署于 Cloudflare Workers 免费额度内即可满足日常需求。
⚡ 原生 TCP Socket：基于 原生接口开发，大幅降低转发延迟。cloudflare:sockets
🤖 TG 机器人联动：集成 Telegram Bot API，支持在 Telegram 内快捷管理配置与提取订阅。
🎯 优选 IP 整合：支持自定义配置 Cloudflare 优选节点（Clean IPS），有效改善网络连接速度。
🛡️ 轻量无依赖：纯单文件/轻量化代码部署，一键复制即可完成构建。
